# Unit 1: BookNest Library (HTML & CSS)

A static web interface for the BookNest Library Management System built using pure HTML5 and CSS3.

## Pages
* `index.html` – Dashboard with summary cards, book catalogue table and genre list.
* `add-book.html` – Form to enter a new book (title, author, ISBN, genre, copies, year, shelf, format, summary).
* `style.css` – Responsive stylesheet (CSS variables, Flexbox, Grid, cards, tables, badges, forms).

## Topics Used
* Semantic HTML5 tags: `header`, `nav`, `main`, `section`, `article`, `footer`
* Tables with `thead` / `tbody`
* Form controls: text, number, select, radio, textarea, built-in validation (`required`, `pattern`, `min`, `max`)
* CSS: custom properties, Flexbox navbar, Grid stat cards, responsive media queries

## How to Run
Open `index.html` in any web browser (double-click the file).
